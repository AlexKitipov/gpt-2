# Security Policy

## Supported Versions
The following table outlines which versions of this project currently receive security updates and patches. Versions not listed as supported should be considered end‑of‑life and will not receive fixes, even for critical vulnerabilities.

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | ✔️ Yes             |
| 5.0.x   | ❌ No              |
| 4.0.x   | ✔️ Yes             |
| < 4.0   | ❌ No              |

---

## Reporting a Vulnerability

We take the security of this project seriously and appreciate responsible disclosures from the community.  
If you believe you have found a security vulnerability, please follow the process below:

### 📩 How to Report
- Send an email to **[maintainer email or security contact]** with:
  - A detailed description of the issue  
  - Steps to reproduce  
  - Potential impact  
  - Any suggested fixes (optional)

### 🔒 Responsible Disclosure
Please **do not** open a public GitHub issue for security vulnerabilities.  
We request that all reports remain private until a fix is released.

### ⏱ Expected Response Time
- You will receive an acknowledgment within **72 hours**.  
- A more detailed response, including whether the issue has been accepted, will follow within **7 days**.  
- Critical issues will be prioritized and addressed as quickly as possible.

### 🛠 If the Vulnerability Is Accepted
If the report is valid, we will:
1. Confirm the issue  
2. Develop and test a fix  
3. Release a patched version  
4. Credit you in the security advisory (optional)

### ❌ If the Vulnerability Is Declined
If the issue is not considered a security vulnerability, we will:
- Provide a clear explanation  
- Suggest alternative reporting channels if applicable

## Security Best Practices for Users

While we aim to provide a secure codebase, users should:
- Always run the latest supported version  
- Avoid using outdated or unsupported releases  
- Review the project’s documentation before deploying in production  
- Apply security patches promptly
